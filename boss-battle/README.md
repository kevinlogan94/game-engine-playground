# Lord of Ash — Phaser boss battle

Landscape desktop demo: approach a fog gate → Dark Souls-style intro → two-phase boss fight.

## Run

```bash
npm install && npm run dev   # http://localhost:5177
```

## Controls

- **WASD / arrows** — move
- **Space** — attack
- **Shift** — dodge (i-frames)
- After death/victory, **Space** retries the fight (skips intro)
